# 🎮 Game Mania Store (Fase 1 - Vanilla JS & SPA)

Uma aplicação Web no modelo **Single Page Application (SPA)** para e-commerce gamer, desenvolvida com HTML5, CSS3, Bootstrap 5 e JavaScript puro (ES6+).

---

## 📌 Visão Geral do Projeto

Este repositório consolida a **Fase 1** da construção da **Game Mania Store**. O objetivo principal foi desenvolver uma vitrine interativa e funcional do zero, aplicando conceitos fundamentais da web sem a dependência de frameworks.

---

## 🚀 Funcionalidades Implementadas

- **Navegação SPA Dynamica:** Troca de telas (Vitrine, Detalhes do Produto e Carrinho) via manipulação direta do DOM.
- **Banco de Dados Centralizado:** Objeto global `PRODUCTS_DB` com catálogo dinâmico de produtos, categorias e especificações.
- **Busca & Filtros em Tempo Real:** Pesquisa inteligente combinando títulos e categorias de produtos.
- **Carrinho de Compras:** Adição de itens, controle de quantidades, remoção e cálculo dinâmico de subtotal com persistência em `localStorage`.
- **Layout Responsivo:** Experiência otimizada para desktops, tablets e smartphones com grid flexível via Bootstrap 5.
- **Controle de Interface:** Ajustes de comportamento de rolagem (`scrollRestoration`) para reset do topo ao atualizar.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 & CSS3:** Estrutura semântica e estilização customizada.
- **Bootstrap 5:** Sistema de grid, componentes responsivos e modais.
- **JavaScript (ES6+):** Lógica da SPA, manipulação de eventos e estado local.
- **Git & GitHub:** Versionamento com padrão de commits semânticos (_Conventional Commits_).

---

## 📅 Linha do Tempo e Evolução do Projeto

1. **Estruturação Inicial:** Criação dos arquivos base, layout responsivo e integração do Bootstrap 5.
2. **Implementação da SPA:** Construção da lógica de exibição de produtos, detalhes e carrinho de compras em página única.
3. **Refatoração & Dados:** Centralização dos produtos no `PRODUCTS_DB` e tratamento de buscas inteligentes.
4. **Estabilização & Ajustes Finos:** Correção de assets, tratamento de falhas em imagens e otimização da experiência mobile.
